# Akshaj Kashyap Portfolio

## Purpose

Build a simple, clean personal website that helps recruiters and technical
reviewers quickly understand Akshaj's strongest projects, experience, skills,
and interests.

## Primary audience

- Software engineering recruiters
- Machine learning recruiters
- Engineers and hiring managers
- Research mentors
- Startup collaborators

## Website structure

1. Navigation
2. Hero
3. Featured projects
4. Additional projects
5. Experience and research
6. About
7. Skills
8. Contact
9. Footer

## Featured projects

- Causal Uplift Experimentation Ops
- Molecular GNN Property Ops
- LLM Posttraining Ops
- Plant Disease VisionOps

## Additional projects

Additional polished projects should remain easily accessible through a compact
homepage section and a dedicated `/projects` page.

## Design direction

- Clean and restrained
- Responsive
- Deep-navy background
- High-contrast off-white text
- Restrained blue, cyan, and violet accents
- Generous whitespace
- Minimal animations
- Strong typography
- No unnecessary backend or database

## Initial requirements

- Next.js App Router
- TypeScript
- Tailwind CSS
- Static local project data
- Responsive navigation
- Reusable project cards
- Dedicated projects page
- Resume download
- GitHub, LinkedIn, and email links
- Accessible semantic HTML
- SEO metadata
- Vercel-ready deployment
