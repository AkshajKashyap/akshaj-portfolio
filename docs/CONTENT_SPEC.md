## Card content order

1. Category eyebrow.
2. Project title.
3. Plain-English summary.
4. Problem / what was built (featured only).
5. Strongest verified evidence/result, with context; omit if absent.
6. Technology tags.
7. Links in priority order: GitHub, Demo, Documentation.

## Copy constraints

- Favor concrete nouns and verbs: `implemented`, `evaluated`, `designed`, `documented`—only when accurate.
- Explain a metric’s context, not just its magnitude.
- Do not use “Passionate about technology,” “Turning ideas into reality,” “Innovative problem solver,” “Aspiring software engineer,” or “Welcome to my portfolio.”
- Keep acronyms expanded on first use when the surrounding text does not make them obvious.
